Entry for the [Rejected Olympic Sports](https://make.fun/c/u-motasimfuad-rejected-olympic-sports-9d83e7da) competition on [make.fun](https://make.fun/).

## What it does

`main.ts` writes one funny single-line sport the Olympics rejected to `/output/entry.txt`:

> Competitive Hide-and-Seek: the last athlete found wins gold. The 2016 champion still hasn't been found.

The line was chosen by an internal head-to-head tournament over 12 candidate one-liners, judged against the competition's own rubric: funniest rejected sport first, the twist lands in one read, it sounds like a real event a broadcaster would have to explain, no wasted words, and quotable.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later. Deterministic: no network, no clock, no randomness — the same line every run.
